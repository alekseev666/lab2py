# Помещения

Лабораторная работа №2. Модули и пакеты Python. ООП (вариант 1, сложность Medium)

## Суть проекта

Консольное приложение на Python для расчёта общей площади помещений и тепловой мощности, необходимой для их обогрева. Помещения описываются тремя объектами: комната, квартира и многоэтажный дом. Результаты расчёта можно сохранить в отчёт формата Word (.docx) или Excel (.xlsx).

## Как использовать

При запуске открывается главное меню:

```
1 - создать дом
2 - демонстрационный дом
0 - выход
```

Пункт `2` загружает готовый дом (ул. Ленина, 5: три квартиры, шесть комнат), его удобно использовать для проверки. Пункт `1` – ввод своего дома:

1. **Ввод дома** – укажите адрес дома и количество квартир.
2. **Ввод квартир и комнат** – для каждой квартиры введите номер и количество комнат, для каждой комнаты – название, длину и ширину в метрах. Высота потолков во всех квартирах одинаковая – 2.5 м, как в обычном панельном доме.
3. **Ввод параметров обогрева** – температура в здании, температура на улице (должна быть ниже, чем в здании) и коэффициент рассеивания (от 0.6 до 4).
4. **Просмотр результатов** – программа выводит площадь и объём каждой квартиры, общую площадь дома и тепловую мощность.
5. **Сохранение отчёта** – выберите формат: `1` – Word, `2` – Excel, `3` – оба, `0` – не сохранять. Отчёты сохраняются в папку `reports`.

После выбранного дома программа показывает его состав (квартиры и комнаты с размерами), шаги 3–5 одинаковы для обоих пунктов. После расчёта программа возвращается в главное меню.

Дробные числа можно вводить и через точку, и через запятую.

## Краткая справка

Площадь комнаты: `S = a * b`

Объём комнаты: `V = a * b * c`, где `c` – высота потолка (2.5 м)

Тепловая мощность: `Q = (V * (T_in - T_out) * K) / 860`, кВт

- `V` – суммарный объём помещений, м³
- `T_in` – температура в здании, °C
- `T_out` – температура на улице, °C
- `K` – коэффициент рассеивания

| Теплоизоляция здания | K |
|---|---|
| Высокая | 0.6 – 0.9 |
| Средняя | 1.0 – 1.9 |
| Низкая | 2.0 – 2.9 |
| Без теплоизоляции | 3.0 – 4.0 |

```
python/

├── README.md

│   ├── premises.py      # Premises – абстрактное помещение, тепловая мощность
│   ├── room.py          # Room – комната: площадь и объём
│   ├── flat.py          # Flat – квартира: список комнат, высота потолка 2.5 м
│   ├── house.py         # House – дом: список квартир
│   └── report.py        # сохранение отчёта в Word и Excel
└── tests/
    └── test_model.py    # тесты pytest
```

### Классы

```
Premises (ABC)
├── Room
├── Flat
└── House
```

- `Premises` – абстрактный базовый класс (`ABC`). Методы `area()` и `volume()` помечены
  `@abstractmethod` и обязательны для наследников. Общий метод `heat_power()` считает
  тепловую мощность для любого помещения. `@staticmethod check_positive()` проверяет,
  что число больше нуля.
- Managed-атрибуты (`@property` + setter с проверкой): `Room.a`, `Room.b`, `Room.c`,
  `Flat.number`, `House.address`. При неверном значении – `ValueError`.
- Dunder-методы:
  - `Premises`: `__eq__`, `__lt__` – сравнение помещений по площади;
  - `Room`: `__repr__`, `__str__`;
  - `Flat`: `__repr__`, `__len__` (число комнат);
  - `House`: `__repr__`, `__len__` (число квартир).

## Как запустить

Установка зависимостей:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Запуск:

```
python main.py
```

Запуск тестов:

```
python -m pytest -v
```
