# Помещения

Лабораторная работа №2. Модули и пакеты Python. ООП (вариант 1, сложность Rare)

## Суть проекта

Консольное приложение на Python для расчёта общей площади помещений и тепловой мощности, необходимой для их обогрева. Помещения описываются тремя объектами: комната, квартира и многоэтажный дом. Результаты расчёта можно сохранить в отчёт формата Word (.docx) или Excel (.xlsx).

## Как использовать

1. **Ввод дома** – укажите адрес дома и количество квартир.
2. **Ввод квартир и комнат** – для каждой квартиры введите номер и количество комнат, для каждой комнаты – название, длину, ширину и высоту в метрах.
3. **Ввод параметров обогрева** – температура в здании, температура на улице и коэффициент рассеивания.
4. **Просмотр результатов** – программа выводит площадь и объём каждой квартиры, общую площадь дома и тепловую мощность.
5. **Сохранение отчёта** – выберите формат: `1` – Word, `2` – Excel, `3` – оба, `0` – не сохранять.

Дробные числа можно вводить и через точку, и через запятую.

## Краткая справка

Площадь комнаты: `S = a * b`

Объём комнаты: `V = a * b * c`

Тепловая мощность: `Q = (V * (T_in - T_out) * K) / 860`, кВт

- `V` – суммарный объём помещений, м³
- `T_in` – температура в здании, °C
- `T_out` – температура на улице, °C
- `K` – коэффициент рассеивания

| Теплоизоляция здания | K |
|---|---|
| Высокая | 0.6 – 0.9 |
| Средняя | 1.0 – 1.9 |
| Низкая | 2.0 – 2.9 |
| Без теплоизоляции | 3.0 – 4.0 |

## Архитектура проекта

```
python/
├── main.py              # интерфейс: ввод параметров, вывод результатов
├── requirements.txt     # зависимости
├── README.md
└── model/               # пакет с классами
    ├── room.py          # Room – комната: площадь и объём
    ├── flat.py          # Flat – квартира: список комнат

    └── report.py        # сохранение отчёта в Word и Excel
```

## Технические требования

- Python 3.10 или новее
- python-docx
- openpyxl

## Как запустить

Установка зависимостей:

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Запуск:

```
python main.py
```
